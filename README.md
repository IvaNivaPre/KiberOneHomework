# 🚀 KIBERone — Платформа для сдачи, хранения и проверки домашних заданий

Веб-приложение для международной КиберШколы будущего **KIBERone**, созданное в фирменном стиле **[moscow.kiber-one.com](https://moscow.kiber-one.com/)** на **FastAPI**, **SQLite**, **HTML / Jinja2 / Tailwind CSS** с поддержкой облачного хранилища **Google Drive**.

## 🌟 Возможности платформы

1. **Интерфейс для детей минимальной сложности:**
   * В личном кабинете ребенка всё разделено на два понятных блока:
     * 🔥 **«СДЕЛАТЬ СЕЙЧАС»** — карточки с заданиями, которые ждут решения, с дедлайнами простыми словами (*«Сдать до субботы»*) и крупной кнопкой *«Сделать задание ➔»*.
     * 🏆 **«МОИ ПОБЕДЫ (СДЕЛАНО)»** — выполненные работы с большими зелеными галочками ✓, оценками ⭐ и отзывами тьютора.
   * Простые и дружелюбные подсказки у полей ввода без сложного сленга:
     * *«Прикрепи файл со своей работой: проект Scratch, картинку или документ»*.
     * *«Напиши сообщение или ответ своими словами: 'Здравствуйте! Я сделал задание, кот прыгает через препятствия...'»*.

2. **Связь с преподавателем вместо чата:**
   * Удобное всплывающее окно **«Связь с преподавателем»** доступно в шапке и на страницах уроков.
   * Прямые ссылки на:
     * ✈️ **Telegram** тьютора (открытие в один клик)
     * 💬 **MAX Ассистент / Чат школы**
     * 📱 **Телефон / WhatsApp**
     * ✉️ **Электронная почта**
   * Тьютор может настраивать контакты прямо на странице настроек платформы!

3. **Светофор выполнения ДЗ для тьютора (Зеленая галочка / Красный индикатор):**
   * Сводная матрица по группе: ученики $\times$ уроки.
   * 🟢 **Зеленая галочка (`СДАНО / ЗАЧТЕНО`):** работа проверена, выставлена оценка и отзыв (или пройден онлайн-тест).
   * 🟡 **Желтый индикатор (`НА ПРОВЕРКЕ`):** ученик сдал работу, ждет проверки.
   * 🔴 **Красный маркер (`НЕ СДАНО / НЕ ПРИСТУПАЛ`):** тьютор за 1 секунду видит, кто не приступал, и не тратит время на поиски.

4. **Интерактивные онлайн-тесты на платформе:**
   * Встроенный конструктор тестов: одиночный выбор, множественный выбор и открытый текстовый ответ.
   * Мгновенная автоматическая проверка и подсчет баллов.

5. **Облачное хранилище Google Drive:**
   * Интеграция с Google Drive API v3.
   * Настроенный родительский каталог (Parent ID): `10Mgxt-wQU26xs_ubKdLQEXbitPtHVkkt`
   * Сервисный аккаунт: `kiberone@kiberone-hw.iam.gserviceaccount.com`

## ⚡ Быстрый запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-сервера
```bash
python run.py
```
Откройте в браузере: **[http://localhost:8000](http://localhost:8000)**
