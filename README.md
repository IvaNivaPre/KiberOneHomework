# KIBERone — Платформа организации и проверки домашних заданий

Веб-приложение для международной КиберШколы KIBERone, разработанное в соответствии со стандартами moscow.kiber-one.com на стеке FastAPI, SQLite, HTML / Jinja2 / Tailwind CSS с интеграцией облачного хранилища Google Drive.

## Ролевая модель и архитектура

В системе предусмотрено три уровня доступа:

1. **Администратор**
   * Обладает полным контролем над платформой.
   * Управляет учетными записями преподавателей (тьюторов), включая их персональные контакты и пароли.
   * Контролирует создание учебных групп, привязку преподавателей к группам, списки учеников.
   * Имеет доступ к глобальным настройкам облачного хранилища Google Drive и мониторингу дедупликации.

2. **Преподаватель (Тьютор)**
   * Создает модули и уроки для назначенных учебных групп.
   * Загружает методические материалы любого формата (PDF, Word, Excel, презентации, проекты Scratch, ссылки на внешние ресурсы) с текстовыми пояснениями.
   * Формирует тестовые задания с автоматической проверкой (одиночный выбор, множественный выбор, текстовый ответ).
   * Проверяет сданные домашние работы резидентов, выставляет оценки и оставляет обратную связь ребенку.
   * Контролирует сдачу по сводной матрице («Светофор»).
   * Указывает свои индивидуальные контакты (Telegram, телефон, email, WhatsApp, MAX) для закрепленных за ним учеников.

3. **Ученик (Резидент)**
   * Личный кабинет с интерфейсом минимальной сложности для детей.
   * Четкое разделение на два экрана:
     * «СДЕЛАТЬ СЕЙЧАС» — актуальные задания с простыми и понятными формулировками дедлайнов.
     * «МОИ ПОБЕДЫ» — сданные и проверенные работы с зелеными индикаторами выполнения, оценками и отзывами преподавателя.
     * Простые подсказки у полей ввода без технического сленга.
     * Загрузка файлов домашних работ (Scratch .sb3, изображения, архивы, документы) или текстовый ответ.
     * Кнопка «Связь с преподавателем» в шапке доступна исключительно ученику и показывает контакты только того преподавателя, который назначен на его группу.

## Контроль выполнения («Светофор»)

Система фиксирует статус выполнения каждого урока:
* **Зеленый индикатор («Зачтено / Сдано»):** работа проверена преподавателем или успешно пройден онлайн-тест. Загорается зеленая отметка.
* **Желтый индикатор («На проверке»):** ученик отправил ответ, работа ожидает оценки преподавателя.
* **Красный индикатор («Не сдано / Не приступал»):** ученик еще не заходил или не отправил ответ. Преподаватель моментально видит этот статус и не тратит время на поиск работ.

## Первичная инициализация учетной записи Администратора

Для обеспечения безопасности и исключения предустановленных учетных записей создание главного администратора вынесено в отдельный консольный скрипт `init_admin.py`.

### Вариант 1. Интерактивный запуск

Запустите скрипт в терминале:

```bash
python init_admin.py
```

Скрипт запросит:
* Логин администратора (по умолчанию: `admin`)
* ФИО администратора (по умолчанию: `Администратор KIBERone`)
* Пароль и подтверждение пароля

### Вариант 2. Запуск с параметрами командной строки

```bash
python init_admin.py --username admin --password secretpassword --name "Анна Иванова"
```

После выполнения скрипта учетная запись администратора будет создана в базе данных, и вы сможете войти в систему по адресу:
`http://localhost:8000/login`

### Создание последующих пользователей

После входа главный администратор добавляет остальных участников через веб-интерфейс:
1. **Преподаватели:** раздел «Преподаватели» (`/admin/tutors`) — кнопка «Добавить преподавателя». В форме указываются ФИО, логин, пароль, а также индивидуальные контакты (Telegram, телефон, email, WhatsApp, MAX).
2. **Группы:** раздел «Группы & Уроки» (`/tutor/groups`) — создание группы с назначением ответственного преподавателя.
3. **Ученики:** в карточке соответствующей группы — добавление логина, пароля и ФИО ученика.

## Облачное хранилище Google Drive

Хранение файлов методических материалов и домашних заданий осуществляется в облачном хранилище Google Drive.

* **Целевая папка (Parent ID):** `10Mgxt-wQU26xs_ubKdLQEXbitPtHVkkt`
* **Сервисный аккаунт:** `kiberone@kiberone-hw.iam.gserviceaccount.com`

### Подключение через OAuth 2.0 (Рекомендуемый способ)

Авторизация через OAuth 2.0 сохраняет файлы от имени аккаунта Google без ограничений квоты сервисных учетных записей.

#### Способ А. Через веб-интерфейс
1. Откройте панель «Настройки Google Drive» (`/tutor/settings`).
2. В блоке загрузки файлов прикрепите файл `credentials.json`, скачанный из Google Cloud Console (тип клиента: Web application или Desktop).
3. Нажмите кнопку «Войти через Google и дать доступ». После подтверждения токен `token.json` автоматически сохранится.

#### Способ Б. Через консольный скрипт
1. Поместите файл `credentials.json` в корень проекта.
2. Запустите скрипт авторизации:
   ```bash
   python setup_oauth.py
   ```
3. Браузер откроет страницу подтверждения Google. После предоставления доступа токен запишется в `token.json`.

### Подключение через Service Account (Для Google Workspace Общих дисков)
Если ваша школа использует корпоративный Google Workspace с «Общими дисками» (Shared Drives):
1. Поместите файл ключа `service_account.json` в корень проекта или загрузите его через форму на странице настроек.
2. Предоставьте сервисному аккаунту `kiberone@kiberone-hw.iam.gserviceaccount.com` права редактора (Editor) на папку `10Mgxt-wQU26xs_ubKdLQEXbitPtHVkkt`.

### Оптимизация и дедупликация файлов

В системе реализован механизм оптимизации дискового пространства Google Drive:
* Перед отправкой каждого файла вычисляется контрольная сумма MD5.
* Проверяется наличие файла с идентичным MD5 на Google Диске и во внутреннем индексе.
* Если файл уже был загружен ранее (например, методичка для нескольких уроков или типовое изображение), он не дублируется. Вместо повторной загрузки создается ссылка на существующий объект на Google Диске.
* Текущая статистика сэкономленного дискового пространства и числа дедуплицированных файлов отображается в панели администратора и настройках хранилища.

## Установка и запуск

### 1. Подготовка окружения

Рекомендуется использовать Python 3.10 или новее.

```bash
git clone <url-репозитория>
cd kiberone_hw
python -m venv .venv
```

Активация виртуального окружения:
* Windows: `.venv\Scripts\activate`
* Linux / macOS: `source .venv/bin/activate`

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Первичная инициализация учетной записи администратора

```bash
python init_admin.py
```

Следуйте подсказкам терминала для создания логина и пароля администратора.

### 4. Авторизация в Google Drive

Убедитесь, что настроен `token.json` или `service_account.json`:

```bash
python setup_oauth.py
```

### 5. Запуск веб-сервера

```bash
python run.py
```

Или напрямую через uvicorn:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Веб-платформа доступна по адресу: **http://localhost:8000**
