# 🚀 KIBERone — Платформа для сдачи, хранения и проверки домашних заданий

Веб-приложение для международной КиберШколы будущего **KIBERone**, созданное на **FastAPI**, **SQLite**, **HTML / Jinja2 / Tailwind CSS** с поддержкой облачного хранилища **Google Drive**.

---

## 🌟 Реализованные возможности и требования

1. **Структура школы (Группы ➔ Модули ➔ Уроки):**
   - Создание и управление учебными группами (по дням недели и курсам).
   - Разбиение курсов на тематические модули (например, *"Модуль 1: Основы Python"*, *"Модуль 2: Разработка игр на Pygame"*).
   - Уроки внутри каждого модуля с отдельными материалами, дедлайнами и заданиями.

2. **Загрузка материалов для ДЗ различного формата:**
   - Поддержка файлов любого формата: **PDF** методички, **Word (.docx)**, **Excel (.xlsx)**, архивы **ZIP**, скрипты **.py**, проекты Scratch **.sb3**, изображения.
   - Ссылки на внешние интерактивные ресурсы (**Repl.it**, **Scratch**, **GitHub**, видеоуроки).
   - Подробные текстовые пояснения и инструкции к каждому уроку.

3. **Интерактивные онлайн-тесты на платформе (Конструктор тестов):**
   - Тьютор может формировать проверочный тест к любому уроку.
   - Поддерживаются 3 типа вопросов:
     - Одиночный выбор (*Single Choice*)
     - Множественный выбор (*Multiple Choice*)
     - Текстовый ввод (*Открытый ответ / точное совпадение*)
   - Автоматическая проверка, подсчет баллов и моментальный расчет процента выполнения.

4. **Различные форматы сдачи ДЗ резидентами:**
   - Выгрузка (прикрепление) готового файла проекта — автоматически загружается на Google Drive.
   - Ответ в текстовом поле на платформе (исходный код, ссылка на онлайн-проект, текстовые пояснения).
   - Возможность сдать как файл, так и текстовое пояснение одновременно.

5. **Личные кабинеты и система авторизации:**
   - Резиденты и тьюторы получают персональный логин и пароль для входа.
   - Безопасные signed HTTP-only cookies (сессия до 7 дней без необходимости постоянного ввода пароля).
   - В кабинете тьютора доступна сводная таблица логинов и паролей детей группы (удобно напомнить ребенку на занятии).

6. **Дедлайны по выполнению ДЗ:**
   - Установка даты и времени дедлайна для каждого урока.
   - Наглядные бейджи с отсчетом времени: *"Осталось: 2 д. 5 ч."* или *"Дедлайн истек!"*.

7. **«Светофор выполнения ДЗ» (Зеленая галочка / Красный индикатор):**
   - 🟢 **Зеленая галочка («СДАНО» / «ЗАЧТЕНО»):** ребенок сдал ДЗ, тьютор проверил работу и выставил оценку / отзыв. Либо сдан обязательный онлайн-тест.
   - 🟡 **Желтый индикатор («НА ПРОВЕРКЕ»):** ребенок прикрепил работу, тьютор сразу видит уведомление о новой сдаче.
   - 🔴 **Красный маркер («НЕ СДАНО / НЕ ПРИСТУПАЛ / ПРОСРОЧЕНО»):** тьютор видит в сводной матрице группы, что ребенок даже не заходил или пропустил дедлайн, и не тратит время на поиски!
   - 🟠 **Оранжевый («ДОРАБОТКА»):** тьютор отправил замечания ребенку на исправление.

```
kiberone_hw/
├── app/

│       │   ├── students.html     # Управление аккаунтами учеников

├── test_app.py               # Автоматические тесты функционала
├── run.py                    # Быстрый запуск uvicorn сервера
```

## ⚡ Быстрый запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Заполнение базы данных демонстрационными данными
```bash
python seed.py
```

### 3. Запуск веб-сервера
```bash
python run.py
```
После запуска откройте в браузере: **[http://localhost:8000](http://localhost:8000)**

## ☁️ Настройка хранения файлов на Google Drive

Платформа спроектирована с архитектурой **Zero-Config Fallback**:
- Из коробки приложение **сразу работает**: если ключи Google Drive еще не добавлены, файлы сохраняются в локальное хранилище `/uploads/` с теми же ссылками и возможностями просмотра.
- При добавлении сервисного аккаунта Google Drive файлы автоматически выгружаются на Google Drive с установкой прав публичного чтения для удобного открытия учениками.

### Пошаговая привязка Google Drive:

1. Откройте [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект (например, `KiberOne-School`).
3. В разделе **APIs & Services ➔ Library** найдите и включите **Google Drive API**.
4. В разделе **IAM & Admin ➔ Service Accounts** создайте сервисный аккаунт:
   - Нажмите *Create Service Account*.
   - Перейдите во вкладку *Keys* ➔ *Add Key* ➔ *Create new key* ➔ выберите формат **JSON**.
5. Скачанный файл сохраните в папку проекта под именем:
   ```
   C:\Users\ivush\.gemini\antigravity\scratch\kiberone_hw\service_account.json
   ```
6. *(Опционально)* Если вы хотите, чтобы все файлы складывались в конкретную общую папку на вашем Google Диске:
   - Создайте папку на Google Диске (например, *"KIBERone Домашние Задания"*).
   - Предоставьте доступ (Editor) для email-адреса созданного сервисного аккаунта (он указан в `client_email` внутри JSON).
   - Скопируйте ID папки из URL браузера и укажите в переменной среды `GDRIVE_FOLDER_ID` или в `app/config.py`.

Статус подключения всегда можно проверить на странице **[http://localhost:8000/tutor/settings](http://localhost:8000/tutor/settings)**.
