Пошаговая инструкция по подключению Google Drive

1

Создайте проект в Google Cloud Console

Перейдите на console.cloud.google.com, создайте проект (например, "KiberOne-Homework").

2

Включите Google Drive API

В разделе APIs & Services → Library найдите Google Drive API и нажмите Enable.

3

Создайте сервисный аккаунт (Service Account)

В разделе IAM & Admin → Service Accounts нажмите Create Service Account. Затем перейдите во вкладку Keys → Add Key → Create new key → JSON.

4

Сохраните файл ключа

Скачанный JSON-файл переименуйте в service_account.json и положите в папку проекта:
C:\Users\ivush\.gemini\antigravity\scratch\kiberone_hw\service_account.json

5

(Опционально) Назначьте общую папку на Google Диске

Создайте папку на Google Диске (например, "KiberOne ДЗ"), откройте к ней доступ (Editor) для email адреса сервисного аккаунта и укажите ID папки в переменной окружения GDRIVE_FOLDER_ID.
